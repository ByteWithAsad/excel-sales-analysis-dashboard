# Excel Interactive Dashboard

This project showcases a complete data analysis workflow using Microsoft Excel, from raw data to interactive dashboard insights.

## Objective
To analyze the dataset and extract meaningful insights using Pivot Tables, KPIs, and visualization techniques.

## Project Structure

- Raw_Data  
  Contains the original dataset used for analysis  

- Pivot_Analysis  
  Pivot tables used to summarize and explore the data  

- Dashboard  
  Interactive dashboard with charts and slicers  

- KPI_Insights  
  Key business questions and their answers  

## Key Features

- Dynamic filtering using slicers  
- KPI-driven analysis  
- Clean and structured dashboard design  
- Data-driven decision insights  

## Skills Demonstrated

- Data Cleaning  
- Pivot Tables  
- Data Analysis  
- Dashboard Design  
- KPI Development  

## Tools Used

- Microsoft Excel
